# AP Physics 1 Rice Cooker Simulation

This is a rice cooker simulation, complete with thorough process descriptions.
 - `latetx.ipynb` Details energy conversion processes and graph creations of Plancks' Law, Malliard Reaction, and Arrhenius Equation
 - `ricecooker.py` Provides a module for rice cooker simulations
 - `Demo.py` details how to simulate a rice cooker using the created module
